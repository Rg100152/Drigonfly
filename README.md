# 🐉 Dragonfly: हवाओं का सिकंदर (The Conqueror of Winds)

Ek adbhut aur preranadayak kahani—ek chhoti si dragonfly (Aron) ke safar ki, jo paani ki andheri gehrayiyon se nikal kar aasman ka raja banta hai. 

Ye project sirf ek kahani nahi hai, balki **cinematic reading experience** hai jo HTML, CSS, aur JavaScript ka use karke banaya gaya hai.

---

## 📖 Kahani Ke Baare Mein (About The Story)

Ye kahani **Neel Sarovar** (एक प्राचीन झील) mein shuru hoti hai, jahan ek nanha sa andaa (egg) phatta hai aur ek nymph (जल-कीड़ा) bahar aata hai. Uska naam **Aron** rakha gaya hai.

Aron apne jeevan mein:
- Paani ke andheri duniya mein shikaari banata hai.
- Moulting (त्वचा बदलना) ke dard se guzarta hai.
- Diving Beetle (पानी का दानव) se bachta hai.
- Mahaan Rupantaran (Metamorphosis) karke aasman ka raja banta hai.
- Red Darter (लाल दानव) se apne ilaake ki raksha karta hai.
- Zephyra se milan karke 'Mating Wheel' banata hai.
- Aur ant mein, ek raja ki tarah apni antim udaan bharta hai.

---

## ✨ Features (Kya Khaas Hai Isme?)

- **🎨 Premium Cinematic Design:** Dark theme, golden accents, aur royal typography.
- **📱 Fully Responsive:** Mobile, tablet aur desktop par perfect dikhta hai.
- **📊 Reading Progress Bar:** Har chapter mein scroll karte waqt progress bar.
- **🌊 Dynamic Home Page:** 12 chapters ka grid, floating images, aur glowing orbs.
- **🖱️ 3D Parallax Effect:** Hero section mein mouse move karne par images move karti hain.
- **📖 Reading Fonts:** Hindi kahani ke liye special `Tiro Devanagari Hindi` font.
- **🔬 Science & Facts:** Unit 11 mein dragonfly ke 8 adbhut vaigyanik tathya.
- **💭 Philosophy:** Unit 12 mein jeevan ki 4 mahatvapurna seekh.

## 🚀 Kaise Chalayein (How to Run)

1. **Project Download karein:**
   - Poora folder apne computer mein save kar lein.
   
2. **Browser mein kholein:**
   - `index.html` file par double-click karein.
   - Ya VS Code mein **Live Server** extension use karein.

3. **Dhyan dein:**
   - Saari files (HTML, CSS, JS, images) ek hi folder mein honi chahiye.
   - Images ka naam `d1.webp` se `d6.webp` tak hi rakhein.
